かくしんと いけんCertitude & opinion

1もう ／ まだ

Dire ce qui est déjà fait ou pas encore. « J'ai déjà mangé » / « Je n'ai pas encore mangé ».
Règle
もう + affirmatif (passé) = déjà · まだ + 〜ていません = pas encore · まだ + affirmatif = encore
Point d'attention
  • Réponse « pas encore » = いいえ、まだです ou 〜ていません — jamais 〜ませんでした.
  • もう + négatif change de sens : もう ありません = il n'y en a plus.
Exemples
  • もう ひるごはんを たべましたか。→ はい、もう たべました。／ いいえ、まだです。
  • でんしゃは もう でました。
  • まだ しゅくだいが あります。j'ai encore des devoirs

2ぶんまつひょうげん 文末表現

Doser à quel point on est sûr de ce qu'on affirme. « C'est sûr » → « c'est peut-être » → « je ne sais pas si… ».
Règle · échelle de certitude
ExpressionCertitude
です・ます100 %
〜と おもいます90 %
〜でしょう80 %
〜だろうと おもいます70 %
〜かもしれません60 %
〜か〜か わかりません50 %
〜かどうか わかりません40 %
Point d'attention
  • Ces formes suivent la forme courte : さむいと おもいます、あめでしょう.
  • 〜か〜か = « si X ou Y » (2 options nommées) ; 〜かどうか = « si oui ou non » (1 seule chose).
  • かもしれません se colle sans だ : あめかもしれません (× あめだかも).
Exemples
  • この みかんは あまいか すっぱいか わかりません。
  • あしたは あめ かもしれません。
  • こんしゅうは ひまですが、らいしゅうは いそがしいだろうと おもいます。
  • あの スーパーは あまり たかくないと おもいます。

3どうし「おもう」 動詞「思う」

Donner son opinion ou une supposition. « Je pense qu'il va venir. »
Règle
[forme courte] + と おもいます
Devant とForme
Verbeくる → くると おもいます
い-adjさむい → さむいと おもいます
な-adjひまだ → ひまだと おもいます
Nomやすみだ → やすみだと おもいます
Point d'attention
  • な-adj et nom gardent だ devant と (× ひまと おもいます).
  • Pour « je pense que NON », on nie le verbe interne : こないと おもいます (plutôt que こると おもいません).
Exemples
  • あ、きょうは やすみだと おもいますよ。
  • リーさんは きょう くると おもいます。
  • いいえ、まだ さむいと おもいます。
りゆうDonner une raison

4から ／ ので

Expliquer la cause de quelque chose. Deux variantes selon le ton. « Comme il pleut, je ne sors pas. »
Sous-notion A — から (subjectif, oral)
[raison, forme polie ou courte] から、[résultat]

Ton direct, personnel. Accepte です／ます devant (あついですから). Peut finir une réponse seule : 「どうして？」→「さむいからです。」

Sous-notion B — ので (doux, poli, objectif)
[raison, forme courte] ので、[résultat]
Devant のでForme
Verbeくる ので
い-adjいたい ので
な-adjすきな ので
Nomびょうきな ので
Point d'attention — LE piège
  • なので mais だから. Pour な-adj et nom : すきなので / あめだから.
  • ので est plus poli → idéal pour une demande : さむいので、まどを しめて いただけませんか。
Exemples
  • びょうきなので、びょういんへ いきます。
  • コーヒーが すきなので、よく のみます。
  • きのう あめが ふったから、せんたくできませんでした。
  • じかんが ないから、はやく してください。
ときSituer dans le temps

5「とき」＋ げんけい／た 時 · 原形／た

Dire « quand… » et surtout à quel moment l'action se passe selon le temps du verbe. « Quand je bois du café, j'ajoute du sucre. »
Règle — ce qui va devant とき
Devant ときForme
Nom+ の → がくせいの とき
な-adj+ な → ひまな とき
い-adjtel quel → あつい とき
Verbeforme dictionnaire ou た (voir ci-dessous)
Règle — verbe : dictionnaire vs た (le cœur de la notion)
Verbe dictionnaire + とき → l'action principale a lieu avant / pendant
Verbe た + とき → l'action principale a lieu après que l'action de とき est finie

Autrement dit : le temps devant とき ne dépend pas de « quand ça se passe vraiment », mais de l'ordre des deux actions entre elles.

Point d'attention
  • Nom + とき = の ; な-adj + とき = な. Ne pas inverser.
  • とき ne prend jamais です／ます／ません devant.
  • ごはんを たべる とき = avant de manger (いただきます) ; ごはんを たべた とき = après avoir mangé (ごちそうさま).
Exemples
  • がくせいの とき、えいごを べんきょうしました。
  • ひまな ときに テレビを みます。
  • べんきょうする とき、じしょが いります。
  • にほんへ くる とき、たくさん ほんを もって きました。apporté avant de venir
  • くにへ かえった とき、ともだちに あいました。vus après être rentré
どうしの タイプTypes de verbes

6どうしの タイプ 動詞のタイプ

Choisir la bonne particule selon la structure du verbe. « La porte s'ouvre » (seule) vs « j'ouvre la porte ».
Règle — 3 types
TypeStructureSens
Type 1Nom が + verbeaction qui se produit seule (intransitif)
Type 2Nom を + verbeaction faite par quelqu'un (transitif)
Type 3Nom に + Nom を + verbeaction avec destinataire (donner/montrer à qqn)
Paires intransitif / transitif à mémoriser
Type 1 · intransitif (が)Type 2 · transitif (を)
みえます se voitみます regarder
きこえます s'entendききます écouter
つきます s'allumeつけます allumer
きえます s'éteintけします éteindre
あきます s'ouvreあけます ouvrir
しまります se fermeしめます fermer
Point d'attention
みえます / きこえます = perception involontaire, toujours が : ふじさんが みえます。
Exemples
  • ふじさんが みえます。Type 1
  • せんせいが テレビを みます。Type 2
  • せんせいが がくせいに しゃしんを みせます。Type 3
ぎゃくせつExprimer l'opposition (« mais »)

7でも ／ けれども ／ しかし ／ が

Relier deux idées opposées. Le choix dépend de où se place le « mais » et du registre. « C'est bon, mais un peu cher. »
Sous-notion A — nouvelle phrase (でも · しかし)
Phrase 1。 でも / しかし、 Phrase 2。

Formalité : でも (familier) → しかし (formel/écrit). Se met en tête, après un point.

Sous-notion B — même phrase (が · けれども)
Proposition 1 が / けれども、 proposition 2。

が suit la forme polie (〜ですが) ; けれども suit la forme courte.

Point d'attention — LE piège d'exam
でも・しかし ouvrent une NOUVELLE phrase · が・けれども relient l'intérieur d'UNE seule phrase.
Exemples
  • この ほんは おもしろいですが、すこし むずかしいです。
  • かんこくの りょうりですが、あまり からく ありません。
  • きのうは あたまが いたかったけれども、やすみませんでした。
  • はるに なりました。でも、あたたかく なりません。
  • にほんの きものは きれいです。しかし、とても たかいです。
けいようしの せつぞくEnchaîner les qualificatifs

8けいようし などの せつぞく 形容詞などの接続

Relier deux qualificatifs devant un nom. « Un restaurant pas cher et bon. »
Règle
い-adj : い → くて → やすくて おいしい
な-adj / nom : で → しずかで おおきい
Point d'attention
  • いい → よくて (× いくて).
  • な-adj garde son な devant le nom final : やすくて きれいな シャツ.
Exemples
  • しろくて いい へやです。
  • やすくて きれいな シャツを かいました。
  • げんきで おもしろい がくせいです。
  • きれいで しずかな こうえんです。
おなじIdentique / différent

9おなじ 同じ

Dire que deux choses sont pareilles ou différentes. « A et B ont le même anniversaire. »
Règle
A と B は おなじです / おなじじゃ ありません · A と B は ちがいます
おなじ + nom (おなじ ほん) · おなじように + verbe
Point d'attention
  • おなじ est un な-adj mais ne prend PAS な devant un nom : ○ おなじ ほん / × おなじな ほん.
  • « différent » n'est pas un adjectif mais le verbe ちがいます.
Exemples
  • たなかさんと マリさんは たんじょうびが おなじです。
  • A と B は ちがいます。
  • せんせいと おなじように かいて ください。
きょかDemander une permission

10〜てもいいですか

Demander ou donner une permission, et dire « pas besoin de ». « Je peux prendre une photo ? »
Règle
Verbe て + も いいですか → puis-je ?
Verbe なくて + も いいです → pas besoin de

Registre montant : 〜てもいいですか → 〜てもかまいませんか → 〜てもよろしいでしょうか.

Point d'attention
  • La négation passe par la forme ない → なくて : たべなくてもいいです.
  • Bien construire la forme て : とる → とって → とっても (× とっと).
Exemples
  • すみませんが、まどを あけてもいいですか。
  • すみません、ここで しゃしんを とってもいいですか。
  • こちらに すわってもよろしいでしょうか。
それともProposer un choix

11せつぞくし「それとも」 接続詞「それとも」

Proposer de choisir entre deux questions. « On mange, ou bien on va au ciné ? »
Règle
〜ますか／ですか。 それとも 〜ますか／ですか。
Point d'attention
それとも relie deux questions, pas deux noms dans une affirmation (pour ça : や／か). Chaque membre garde son か.
Exemples
  • しょくじしましょうか。それとも えいがを みましょうか。
  • ジュースが いいですか。それとも コーラが いいですか。
  • スーパーで かいますか。それとも コンビニで かいますか。
ばしょの じょしParticules de lieu

12かんけいじょし「に・で・を」 関係助詞

Choisir に / で / を autour d'un lieu selon le rapport à l'action. « Entrer dans / agir dans / sortir d'un lieu. »
Règle — le trio sur un même lieu
Lieu に はいります → entrer dans
Lieu で 〜します → agir dans
Lieu を でます → sortir de
Point d'attention
を marque aussi la sortie (でます), pas seulement l'objet direct.
Exemples
  • デパートに はいります。／ デパートで かいものします。／ デパートを でます。
  • きっさてんに はいります。／ きっさてんで コーヒーを のみます。／ きっさてんを でます。
に ＋ ほうこうの どうしAller pour faire

13「に」＋ ほうこうの どうし に＋方向の動詞

Exprimer le but d'un déplacement. « Je vais à Shinjuku pour manger. »
Règle
Lieu へ + base ます + に + いきます／きます／かえります
Point d'attention
  • On enlève ます : たべます → たべに.
  • Noms en する : だしに / べんきょうに ou べんきょうしに.
  • L'objet reste avant la base : てがみを だしに いきます.
Exemples
  • ゆうびんきょくへ てがみを だしに いきます。
  • おそばを たべに いきましょう。
  • にほんへ にほんごの べんきょうに きました。
めいしを せつめいするDécrire un nom · capacité

14どうし ＋ めいし 動詞＋名詞 (proposition relative)

Décrire un nom avec une phrase entière placée avant lui. « Le livre que j'ai acheté hier. »
Règle
[phrase en forme courte] + nom — sans particule entre les deux
Point d'attention
  • Le sujet interne à la description prend が, pas は : （わたしが）かった ほん.
  • Verbe en forme courte : かった (× かいました) devant le nom.
Exemples
  • これは、きのう かった ほんです。
  • リーさんは あかい シャツを きている ひとです。
  • あした みる えいがは なんですか。
  • けさ みた サッカーの しあいです。

15ことが できる

Exprimer une capacité ou une possibilité (registre formel). « Je sais lire les kanji. »
Règle
Verbe dictionnaire + ことが できます
Point d'attention
  • Verbe en forme dictionnaire : のむ ことが できます (× のみます ことが).
  • L'objet garde を : かんじを よむ ことが できます.
  • À ne pas confondre avec 〜た ことが あります (expérience passée).
Exemples
  • かんじを よむ ことが できます。
  • おさけを のむ ことが できません。
  • にほんりょうりを つくる ことが できますか。→ ええ、できます。
そんざいと ばしょExistence & localisation

16どうし「ある／いる」 存在

Dire où se trouve une chose ou une personne. « Le stylo est sur le bureau. »
Règle
Chose / plante は lieu に あります
Personne / animal は lieu に います
Point d'attention
あります = inanimé · います = vivant. Honorifique de います : いらっしゃいます.
Exemples
  • ペンは つくえの うえに あります。
  • たなかさんは 2かいに います。
  • せんせいは きょうしつに いらっしゃいます。

17かんけいじょし ＋ せんたくじょし に＋も / に＋は

Dire « à X aussi et à Y aussi », ou opposer deux lieux. « Il y a des grands magasins à Shinjuku comme à Ikebukuro. »
Règle
Lieu にも … Lieu にも あります／います → « à l'un aussi et à l'autre aussi »
Lieu には ありません → contraste : « à ce lieu-là, par contre, il n'y en a pas »
Point d'attention
にも = に (lieu) + も (aussi) · には = に + は (contraste). C'est le も / は qui change tout le sens.
Exemples
  • デパートは しんじゅくにも いけぶくろにも あります。aux deux endroits
  • きょうしつは 1かいにも 2かいにも あります。
  • デパートは たかだのばばに ありません。しんじゅくには あります。à Shinjuku par contre, oui
  • アメリカにも フランスにも ともだちが います。
〜めLe Nième

18じすうし ＋ め 時数詞＋目

Dire la position de quelque chose dans une série. « La 3ᵉ personne à partir de la droite. »
Règle
compteur + 目（め） → 2つめ、3にんめ、3つめ
Point d'attention
Sans 目 = on compte (ふたつ = deux). Avec 目 = on classe (ふたつめ = le deuxième). Souvent avec から pour le point de départ.
Exemples
  • デパートは かどから 3つめです。
  • みぎから 3にんめが ハンさんです。
  • たかだのばばは、いけぶくろから 2つめです。
ひかくComparer

19ひかくの ひょうげん 比較

Comparer des éléments : à deux, un extrême, ou « pas autant que ». « Je préfère le poisson à la viande. »
Sous-notion A — comparer deux éléments
Q : A と B と どちらの ほうが 〜ですか
R : A より B の ほうが 〜です

より se colle à l'élément battu. どちらも 〜です = « les deux ».

Sous-notion B — superlatif (le plus…)
[groupe]の なかで 〜が いちばん 〜です

La question utilise なに／だれ／どれが (jamais は). L'élément choisi prend が.

Sous-notion C — pas autant que
A も 〜ですが、 B ほど じゃありません

ほど est toujours suivi d'une négation. Jamais ほどです.

Point d'attention — les 3 mots-clés
より (le battu) · のほうが (le gagnant) · ほど + négatif (pas au niveau de).
Exemples
  • うえださんと きむらさんと どちらの ほうが せが たかいですか。→ うえださんより きむらさんの ほうが せが たかいです。
  • くだものの なかで さくらんぼが いちばん すきです。
  • にほんで いちばん たかい やまは ふじさんです。
  • ラーメンも すきですが、おすしほど じゃ ありません。
  • しんかんせんは ひこうきほど はやく ありません。
〜さAdjectif → nom

20けいようし ＋ さ 形容詞＋さ

Transformer un adjectif en nom de mesure. « La hauteur, le poids, la taille de… »
Règle
い-adj (retirer い) / な-adj + さ → たかい → たかさ
Point d'attention
Surtout pour les mesures : たかさ (hauteur), おもさ (poids), ひろさ (superficie), ながさ (longueur). Ne pas confondre avec 〜そう (apparence).
Exemples
  • へやの ひろさは どのぐらいですか。
  • スカイツリーの たかさは 634メートルです。
  • ひこうきに のる ときに かばんの おもさを はかります。
こうどうを つなぐOrdonner & enchaîner des actions

21まず ／ それから

Ordonner des étapes successives. « D'abord…, ensuite… »
Règle
まず、〜。 それから、〜。
Point d'attention
それから enchaîne des actions (≠ それとも qui propose un choix).
Exemples
  • まず、ひらがなを べんきょうします。それから、カタカナを べんきょうします。
  • まず、なまえを いって ください。それから、よんで ください。

22どうし て、どうし ／ どうし ないで、どうし

Deux actions liées : l'une puis l'autre, ou l'une sans l'autre. Sens opposés, à ne pas confondre. « Je rentre et je mange » vs « j'étudie sans regarder la télé ».
Sous-notion A — て : faire X, puis Y
Verbe て、 verbe。 → actions successives, même sujet
Sous-notion B — ないで : faire Y sans faire X
Verbe ないで、 verbe。 → « sans / au lieu de »
Point d'attention
  • Le temps est porté par le dernier verbe.
  • Bien maîtriser て (かえる → かえって) et ない (みる → みないで).
Exemples
  • いえへ かえって、ごはんを たべます。puis
  • ともだちに あって、いっしょに しょくじしました。puis
  • テレビを みないで、べんきょうしました。sans
  • さとうを いれないで、コーヒーを のみます。sans
なる ／ するDevenir / rendre

23なる ／ する — changement d'état

Un changement subi (なる, ça devient) ou voulu (する, je rends). Même mécanisme, actif vs passif. « Il fait plus chaud » vs « je réchauffe la soupe ».
Sous-notion A — なる : devenir (subi)
い-adj → く なる → あたたかく なります
な-adj / nom → に なる → しずかに / しゃちょうに なります
Verbe potentiel + ように なる → en venir à pouvoir : たべられるように なりました
Sous-notion B — する : rendre (voulu)
い-adj → く する → おおきく します
な-adj → に する → しずかに します
Point d'attention
  • Même bascule pour les deux : い-adj → く · な-adj → に.
  • なる = ça devient tout seul · する = je le rends volontairement.
  • 〜ようになる = acquisition progressive d'une capacité.
Exemples
  • びょうきでしたが、げんきに なりました。devenu
  • もうすぐ あたたかく なります。devient
  • にほんごが すこし わかるように なりました。j'en suis venu à comprendre
  • へやを きれいに します。je rends
  • この スープは ぬるいですね。あたたかく しましょう。rendons-la chaude
けいようし → ふくしAdjectif → adverbe

24けいようし ＋ どうし 形容詞＋動詞 (adverbe)

Transformer un adjectif en adverbe pour modifier un verbe. « Écris grand. » / « Écris proprement. »
Règle
い-adj : い → く + verbe → おおきく かきます
な-adj : + に + verbe → きれいに かきます
Point d'attention
Même logique que « devenir / rendre » : い-adj → く · な-adj → に.
Exemples
  • おおきく かいて ください。
  • ひらがなを きれいに かきましょう。
  • にほんごの うたを じょうずに うたいたいんです。
〜そうAvoir l'air de

25〜そう — apparence

Dire qu'une chose a l'air de… (impression visuelle). « Ce gâteau a l'air bon. »
Sous-notion A — forme de base
い-adj (retirer い) + そうです → おいしそうです
Verbe (base ます) + そうです → ふりそうです ça a l'air d'aller pleuvoir
négatif : 〜くなさそうです → たかくなさそうです
Sous-notion B — devant un nom / un verbe
〜そうな + nom → おもしろそうな ほん
〜そうに + verbe → おいしそうに たべます
Point d'attention
  • Exceptions : いい → よさそう · ない → なさそう.
  • そう d'apparence (base ます / adj sans い) ≠ そう d'ouï-dire (forme courte + そうだ : びょうきだったそうです = « il paraît que »).
  • Devant nom → そうな · devant verbe → そうに.
Exemples
  • この ケーキは おいしそうです。
  • あめが ふりそうです。
  • この みせは、あんまり たかくなさそうです。
  • これは、おもしろそうな ほんですね。
  • がくせいが たのしそうに はなして います。
きめるDécider de

26〜にする ／ 〜ことにする

Exprimer un choix ou une décision. « Je vais prendre un café. » / « J'ai décidé de déménager. »
Règle
Nom / compteur + に します → コーヒーに します choix
Verbe dictionnaire / ない + こと + に します → いくことにします décision d'action
Point d'attention
  • 〜にする pour un choix (menu, date) · 〜ことにする pour décider une action.
  • Négation : 〜ないことにします (je décide de ne pas…).
  • Nuance : 〜ことにする = je décide · 〜ことになる = c'est décidé (par l'extérieur).
Exemples
  • コーヒーに します。
  • パーティーは らいしゅうに しましょう。
  • いまの へやは せまいから、ひっこしすることに しました。
  • あしたから たばこを すわないことに します。

✅ Checklist express avant l'exam

  1. だから ↔ なので — だ pour から, な pour ので.
  2. でも・しかし = nouvelle phrase / が・けれども = même phrase.
  3. とき : nom+の, な-adj+な · verbe dictionnaire (avant) vs た (après).
  4. ことができます (capacité, verbe dictionnaire + を) ↔ たことがあります (expérience).
  5. みえます・きこえます → particule が (perception involontaire).
  6. Relative : sujet interne en が, verbe en forme courte.
  7. Comparaison : より (battu) / のほうが (gagnant) / ほど + négatif.
  8. にも (aussi) ↔ には (contraste).
  9. Changement : い-adj → く, な-adj → に (なる / する / adverbe).
  10. なる (subi) ↔ する (voulu) ↔ にする (décision).
  11. そう apparence (base ます / adj sans い) ↔ そう ouï-dire (forme courte + だそう).
  12. いい → よくて / よくない / よさそう (jamais いく…).
  13. Permission : とる → とって → とっても (× とっと).
  14. 目 : sans = on compte · avec = on classe (le Nième).
